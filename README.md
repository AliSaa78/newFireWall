#Clincal Mangament System API 

A Restful API built using Node.js and express.js

## Features

- User authentication with JWT
- Role-based authorization
- CRUD operations for:
  - Patients
  - Invoices
  - Prescriptions
- Password reset via email(Not finished yet)
- File upload using multer (e.g., patient pictures)
- Swagger API documentation
- QR code generation for patients

## Technologies

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT
- bcrypt
- Multer
- Swagger (OpenAPI 3.0)
- Mailtrap (for testing email)
